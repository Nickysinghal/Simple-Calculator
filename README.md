# Simple Calculator

A simple, responsive calculator built using HTML, CSS, and JavaScript.
It performs basic arithmetic operations with a modern glassmorphism + neumorphic UI design.

## Features

- Basic arithmetic operations  
- AC button – clears the display  
- DEL button – deletes the last digit  
- Responsive design (desktop & mobile)  
- Modern glassmorphism + neumorphic UI  

## Project Structure
```
calculator/
│── index.html   # Main HTML file  
│── style.css    # Calculator styling  
│── script.js    # Button functionality  
│── README.md    # Project description  
```

## Technologies Used

- HTML5  
- CSS3  
- JavaScript
